1 — Nuevo usuario / Onboarding
1
initAuth() → carga Clerk, detecta plan del usuario
2
Clic en agente → openAgent(key)
3
Si no hay perfil guardado → renderOb() — 9 preguntas adaptadas por agente
4
finishOb() → guarda perfil en localStorage / Supabase y abre chat
2 — Chat con agente (turno normal)
1
Usuario escribe + Enter → sendMsg()
2
callClaude() → POST /api/chat · system prompt con {MEMORY}, {STAGE}, {AGENT}
3
SSE stream → tokens en tiempo real → frontend detecta bloques especiales en el output
4
Ejecuta acción del bloque (GAQL query, genera imagen, exporta, etc.)
5
Guarda conversación en Supabase / localStorage
3 — WAR (Weekly Account Review)
1
warOpen(clientId) desde el botón "reporte" en la tarjeta del cliente
2
Pasos 1–4: plataforma → KPIs → período → ingreso de métricas
3
warGenerate() → POST /api/report → genera URL pública en Supabase
4
Copiar link o enviar por WhatsApp directo
4 — Parrilla Social → Google Sheets
1
Agente genera parrilla y emite [PARRILLA_LISTA]
2
Frontend renderiza 4 botones: Sheets, Imágenes, PDF, Cerrar
3
exportToSheets() → POST /api/create-sheet → URL del Google Sheet
4
Opcional: generarImagenesParrilla() → prompt automático para imágenes de posts
5 — Generación de imagen de anuncio
1
Agente emite [GENERAR_IMAGEN: {prompt, format, variations}]
2
canGenerateImage() valida límite según plan del usuario
3
POST /api/generate-image → fal.ai / Ideogram
4
renderAdImage() → grid horizontal scrolleable con descargar / publicar a Meta

[GAQL_QUERY]
Google Ads Query
Ejecuta una query GAQL contra la cuenta conectada. El resultado se integra automáticamente en el siguiente turno del agente.
[META_API]
Meta Ads API
Llama a la Graph API de Meta con endpoint, method y params. La respuesta vuelve al agente para análisis o acciones.
[GENERAR_IMAGEN]
Generar imagen de anuncio
Dispara POST /api/generate-image con prompt, formato y número de variaciones. Renderiza un grid horizontal con las imágenes.
[PARRILLA_LISTA]
Parrilla lista para exportar
Activa los botones de exportación: Google Sheets, Generar imágenes, Exportar PDF.
[GENERAR_IMAGENES_PARRILLA]
Imágenes para posts de parrilla
Prepara un prompt automático para generar una imagen por cada post de la parrilla de contenido.
[SOCIAL_OPTIONS]
Opciones del agente social
Renderiza 6 botones de acción rápida: diagnóstico, parrilla, estrategia, copys, análisis de rendimiento, viral.
[SUGERENCIAS]
Preguntas sugeridas
Formato: [SUGERENCIAS: opción1 | opción2 | opción3]. Renderiza 3 botones de follow-up al final de cada respuesta del agente.
[AGENTE_SUGERIDO]
Sugerencia de agente especializado
Solo en el home chat general. Propone al usuario cambiar al agente especializado: [AGENTE_SUGERIDO: google-ads].
